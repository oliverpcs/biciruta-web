# BiciRuta

Web de la tienda de bicicletas BiciRuta.

## Estructura

- index.html: estructura y contenido de la web
- css/estilos.css: estilos
- js/app.js: menú y carrito
- img/: imágenes (logotipo)
- README.md: este archivo
- .gitignore: ficheros que Git no guarda

## Cómo verla con Live Server

1. Abrir la carpeta biciruta-web en VS Code.
2. Abrir index.html.
3. Pulsar Go Live en la barra de abajo.
4. Se abre en el navegador en http://127.0.0.1:5500
